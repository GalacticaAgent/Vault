# Vault/Radiant 前端项目

## 项目简介
基于 Vue.js 3.x 的前端应用，为 Vault/Radiant 智能教学系统提供用户界面。

## 技术栈
- Vue.js 3.x
- Element Plus (UI 组件库)
- Vue Router (路由管理)
- Pinia (状态管理)
- Vite 4.x (构建工具)
- Axios (HTTP 客户端)
- Markdown-it (Markdown 渲染)
- ECharts (数据可视化)

## 核心功能
### 学生端
- 智能问答对话
- 问卷答题
- 个人学习肖像查看
- 代码仓库提交
- 可定制学习看板

### 教师端
- 智能分析对话
- 问卷创建与管理
- 学习资料管理
- 学生肖像分析
- 班级统计分析
- 可定制分析看板

## 开发环境要求
- Node.js 16+
- npm 或 pnpm

## 快速开始
```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```
