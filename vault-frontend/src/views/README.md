# Views 视图层

## 职责
定义页面级组件，组合各种组件形成完整页面。

## 目录结构

### auth/ - 认证页面
用户认证相关页面。

#### Login.vue
登录页面
- 用户名/密码登录
- 角色选择（学生/教师）
- 记住密码
- 跳转注册

#### Register.vue
注册页面
- 用户信息填写
- 角色选择
- 表单验证
- 跳转登录

### student/ - 学生端页面
学生功能页面。

#### Dashboard.vue
学生看板
- 统计卡片（答题数、平均分、排名）
- 自定义查询卡片
- 数据可视化

#### Chat.vue
智能问答
- 对话列表
- 消息展示
- 流式响应
- 附件上传
- 会话分享

#### Questionnaire.vue
问卷答题
- 问卷列表
- 题目展示
- 答案提交
- 进度保存
- 查看成绩

#### Profile.vue
个人肖像
- 知识掌握度
- 薄弱知识点
- 学习曲线
- 代码质量
- 年度报告

#### CodeSubmit.vue
代码提交
- 仓库 URL 提交
- 分析进度查看
- 分析结果展示

### teacher/ - 教师端页面
教师功能页面。

#### Dashboard.vue
教师看板
- 学生统计
- 班级统计
- 自定义分析卡片

#### Chat.vue
智能分析
- 教学问题咨询
- 学生情况分析
- 知识图谱查询

#### QuestionnaireCreate.vue
问卷创建
- 手动创建问卷
- AI 生成问卷
- 题目编辑
- 目标学生选择
- 问卷发布

#### MaterialManage.vue
资料管理
- 资料上传
- 资料分类
- 资料编辑
- 知识图谱关联

#### StudentAnalysis.vue
学生分析
- 单个学生肖像查看
- 知识点分析
- 学习轨迹
- 代码分析结果

#### ClassAnalysis.vue
班级分析
- 班级整体统计
- 知识点掌握分布
- 学生对比
- 薄弱点汇总

### common/ - 公共页面

#### NotFound.vue
404 页面
- 页面不存在提示
- 返回首页

#### Forbidden.vue
403 页面
- 权限不足提示
- 返回首页
