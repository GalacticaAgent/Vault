# Vault/Radiant 数据库设计

## 数据库信息
- 数据库类型：MySQL 8.0+
- 字符集：utf8mb4
- 排序规则：utf8mb4_unicode_ci

## 表结构分类

### 用户相关表
- `user` - 用户表
  - 存储学生和教师的基本信息
  - 角色区分（STUDENT/TEACHER）
  - 密码加密存储

### 知识图谱相关表
- `kg_node` - 知识图谱节点表
  - 节点类型：资料、个人、代码仓库、问题、答案、知识点
  - 包含向量数据用于相似度检索
- `kg_relation` - 知识图谱关系表
  - 关系类型：属于、引用、掌握、薄弱、相关
  - 源节点和目标节点关联

### 对话相关表
- `chat_session` - 对话会话表
  - 用户会话管理
  - 支持会话分享
- `chat_message` - 对话消息表
  - 消息角色：用户、助手、系统
  - 消息内容和附件

### 问卷相关表
- `questionnaire` - 问卷表
  - 问卷基本信息
  - 发布状态管理
- `question` - 题目表
  - 题目类型：单选、多选、判断、简答、编程
  - 题目内容、选项、答案
- `questionnaire_submission` - 问卷提交表
  - 学生答题记录
  - 评分和批改结果

### 代码分析相关表
- `code_repository` - 代码仓库表
  - GitHub/GitLab 仓库信息
  - 仓库分析状态
- `code_analysis_result` - 代码分析结果表
  - 代码质量分析
  - Bug 检测结果
  - AI 生成痕迹检测

### 肖像相关表
- `student_profile` - 学生肖像表
  - 知识掌握度
  - 学习行为数据
  - 代码能力评分
- `knowledge_tracing` - 知识追踪表
  - 知识点掌握度追踪
  - 历史记录

### 看板相关表
- `dashboard_config` - 看板配置表
  - 用户看板布局配置
- `custom_card` - 自定义卡片表
  - 自定义查询卡片
  - 卡片类型和刷新间隔

## SQL 文件说明

### schema.sql
完整的数据库建表语句
- 所有表的创建语句
- 索引定义
- 外键约束（如适用）

### init_data.sql
初始化数据
- 测试用户数据
- 基础配置数据

### migration/
数据库迁移脚本
- 版本化的数据库变更
- 按时间顺序命名

## 索引策略
- 主键索引：所有表的 id 字段
- 唯一索引：用户名、学号、邮箱等唯一字段
- 普通索引：常用查询字段（user_id, session_id 等）
- 全文索引：需要全文检索的字段（标题、内容）
- 复合索引：多字段联合查询

## 备份策略
- 每日定时备份
- 增量备份
- 备份文件加密存储
