# Utils 工具类层

## 职责
提供各种工具方法，简化开发，提高代码复用性。

## 主要工具类

### JwtTokenUtil.java
JWT Token 工具类
- 生成 Token
- 解析 Token
- 验证 Token
- 刷新 Token
- 获取用户信息

### PasswordUtil.java
密码工具类
- 密码加密（BCrypt）
- 密码验证
- 随机密码生成

### RedisUtil.java
Redis 操作工具类
- 字符串操作
- Hash 操作
- List 操作
- Set 操作
- 设置过期时间

### HttpUtil.java
HTTP 请求工具类
- GET 请求
- POST 请求
- 文件上传
- 文件下载

### JsonUtil.java
JSON 处理工具类
- 对象转 JSON
- JSON 转对象
- 格式化输出

### DateUtil.java
日期工具类
- 日期格式化
- 日期解析
- 日期计算
- 时间戳转换

### StringUtil.java
字符串工具类
- 空值判断
- 驼峰转下划线
- 随机字符串生成
- 字符串脱敏

### FileUtil.java
文件工具类
- 文件上传
- 文件下载
- 文件类型判断
- 文件大小格式化

### ValidationUtil.java
验证工具类
- 邮箱验证
- 手机号验证
- 身份证验证
- URL 验证

### MarkdownUtil.java
Markdown 处理工具类
- Markdown 转 HTML
- 代码高亮
- 数学公式渲染
