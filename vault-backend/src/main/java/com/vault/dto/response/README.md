# Response DTO

## 职责
定义响应数据传输对象。

## 主要 DTO

### LoginResponse.java
登录响应
- Token
- 用户信息

### MessageResponse.java
消息响应
- 消息内容
- 参考资料
- 使用的 Skills

### DashboardResponse.java
看板响应
- 固定卡片数据
- 自定义卡片数据

### QuestionnaireResponse.java
问卷响应
- 问卷信息
- 题目列表

### StudentProfileResponse.java
学生肖像响应
- 知识点掌握度
- 薄弱知识点
- 学习曲线
