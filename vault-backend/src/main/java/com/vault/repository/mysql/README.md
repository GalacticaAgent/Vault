# MySQL Repository 层

## 主要仓库接口

### UserRepository.java
用户数据仓库
- 用户基本信息查询
- 用户角色查询
- 用户认证相关

### ChatRepository.java
对话数据仓库
- 对话创建与管理
- 对话列表查询
- 对话分享相关

### MessageRepository.java
消息数据仓库
- 消息保存与查询
- 消息历史记录
- 消息关联查询

### QuestionnaireRepository.java
问卷数据仓库
- 问卷创建与管理
- 问卷查询
- 问卷状态管理

### QuestionRepository.java
题目数据仓库
- 题目管理
- 题目查询
- 题目关联

### AnswerRepository.java
答案数据仓库
- 答案保存
- 答案查询
- 答案统计

### MaterialRepository.java
资料数据仓库
- 资料上传与管理
- 资料查询
- 资料分类

### SkillRepository.java
Skill 数据仓库
- Skill 上传与管理
- Skill 查询
- Skill 执行记录
